# Static Assets Folder

## Favicon Setup

Place your `fav.png` file in this folder.

### Recommended Favicon Specifications:
- **Format:** PNG (with transparency)
- **Size:** 32x32 pixels or 64x64 pixels (will be scaled automatically)
- **Design:** Based on ALGOWAR theme - Tokyo Night Cyberpunk + Traditional Japanese
- **Suggested designs:**
  - Japanese lantern with neon glow
  - Crossed code brackets `{ }` in neon colors
  - Kanji character 戦 (battle) with cyberpunk styling
  - Tournament bracket icon

### Color Palette:
- Neon Cyan: #00E5FF
- Neon Gold: #FFB703
- Neon Magenta: #FF2E63
- Dark Background: #0B0F1A

Once you place `fav.png` in this folder, it will automatically appear as the browser favicon.
